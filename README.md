# LaserToolFX

Générateur gratuit de boîtes, coffres et formes pour découpe laser — SVG prêts à découper.

**Utilisation :** https://akinasfx.github.io/LaserTool/

Ouvre le lien dans Chrome ou Edge. Pour l'avoir comme une vraie application (icône, fenêtre dédiée, sans barre d'adresse), clique sur l'icône d'installation dans la barre d'adresse du navigateur (ou le menu ⋮ → "Installer LaserToolFX").

Par [NeoprodFX](https://github.com/AkinasFX).
